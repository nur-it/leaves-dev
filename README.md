# LEAVES - Family Memories Platform

A beautiful web application for preserving and sharing family memories, stories, and legacy content across generations.

## 📖 Overview

LEAVES is a family-focused digital platform that helps families capture, preserve, and share their stories, memories, and important moments. The platform includes features for storytelling, media management, timeline creation, and legacy preservation.

The complete design system and UI components are available in Figma:

## ✨ Features

- **Dashboard** - Central hub for family activities and updates
- **Times of My Life®** - Record and organize life stories
- **Forever Voice™** - Capture audio memories and personal narratives
- **Life Map™** - Visualize important locations and journeys
- **Life Timeline™** - Chronicle life events chronologically
- **Document Archive™** - Secure storage for important documents
- **Legacy Letters™** - Write messages for future delivery
- **Media Library™** - Organize photos and videos

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first styling via CDN
- **Font Awesome** - Icon library
- **Google Fonts (Inter)** - Typography

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process required - all dependencies loaded via CDN
